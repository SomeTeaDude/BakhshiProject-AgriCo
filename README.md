# BakhshiProject-AgriCo

This is the raw html css js version of the application

It actually works, but everything is on the client side. Everything is js-based. There is zero backend in this project.

As a matter of fact, it doesn't even have a `node_modules` or `vendor` folder!

**NOTE:** This was the first version of the project's ui (not created by me). Later then, i updated most of its parts and even added new pages and components. If you are comparing it with the main project, please consider this.

**Fun Fact:** A fact about this project is that, even though this was the first version of the site, which means it was completely based on js, i had to move it to Laravel and adapt everything with Livewire.

It may seem fun, but it was a hard choice actually. I literally had to use Livewire for everything js-related.
The only *custom* js file that you will see in the main project is the `home.js` file. Which i also had to shorten because most of it became useless as i was using Livewire instead of vanilla js.
